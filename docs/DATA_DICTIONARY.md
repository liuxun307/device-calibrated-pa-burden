# DATA DICTIONARY — released tables

Every CSV in `output/` is a **derived artefact** regenerated by the pipeline; none is hand-edited.
Column names are lower_snake_case and stable. `paf` = population attributable fraction; `fold` =
recomputed ÷ GBD-reported; `MIMS` = Monitor-Independent Movement Summary units (device scale, wrist).
Files are UTF-8 **with BOM** (Excel compatibility) — read with `encoding = "UTF-8-BOM"`.

## 1. Sample and exposure (Fig 2)

### `Fig2a_flow_numbers.csv` — two-stage sample definition
| Column | Meaning |
|---|---|
| `node` | Flow node: `Aged >= 25` (device sample) / `Linked mortality` / `Modelling sample` |
| `n` | Participants at that node |
| `deaths` | Deaths observed (NA on the top node) |
| `cvd_deaths` | Cardiovascular deaths (UCOD_LEADING 1 or 5) |

> **Two-stage reporting**: device sample **7,854** (Table 1 target) → **7,842** with mortality linkage
> (769 deaths) → multivariable Cox set **7,007** (664 deaths, 207 CVD). Do not mix denominators.

### `Fig2b_exposure_summary.csv` — headline exposure proportions
| Column | Meaning |
|---|---|
| `metric` | `Meets WHO guideline (self-reported, weighted)` or `Below TMREL (device-measured, weighted)` |
| `pct_weighted` | Weighted percentage (61.7123 / 51.1106) |
| `n_unweighted` | Unweighted denominator (7,854) |
| `w_sum` | Sum of examination weights |
| `threshold`, `threshold_unit` | 600 MET-min/wk (self-report) / 13,222.0729 MIMS/day (device) |

### `Fig2c_crosstab_weighted.csv` — self-report × device quartile
| Column | Meaning |
|---|---|
| `sr` | Self-reported category: `inactive` / `low` / `moderate` / `high` |
| `dev` | Device quartile: `Q1`–`Q4` |
| `n` | Unweighted cell count |
| `wsum` | Weighted cell sum |
| `pct` | Row percentage (within `sr`) |

> Derived read-outs used in the text: self-reported `inactive` → Q2–Q4 = **67.04%**; weighted share in Q1
> across all `sr` = **23.42%**; self-reported `high` → Q1+Q2 = **29.2%**.

### `Table1_baseline_manuscript.csv` — weighted baseline characteristics
`variable` × `Overall` / `Q1`–`Q4` (device quartiles); cells are `mean (SE)` or `% (SE)`; first two rows are
`N` and `Deaths`. Last two rows: self-reported MET-min/week and device MIMS/day.

### `Sample_definition.csv` — 8-row denominator ledger
`item`, `n`, `note`. Includes both stages, CVD deaths in the Cox set (207), and the 780 mortality-linkage count.

## 3. Calibration and reporting bias (Fig 4, Table 3)

### `Table3_calibration.txt`
Human-readable calibration equation: intercept **16,024.7 (SE 208.0)**, natural-spline terms
(3,475 / 3,694 / 1,930), R² **0.191**, residual standard error **3,337** (lm, df = 7,847).

### `QC_08d_calibration_check.csv`
`item`, `value_08d`, `value_chain` — cross-script equality check. `resid_SD = 3,335.36` here is
`sd(residuals)` (n−1); **this is the σ used in the Module 3 convolution** (the lm value 3,337 is not).

### `Table3_reporting_bias.csv`
`meets_600`, `mims_mean`, `n` — device-measured activity by self-reported guideline attainment
(13,908 / 12,431; difference 1,477 MIMS/day ≈ 12%).

### `Table3_sd_mean_relation_coefs.csv`
`model`, `scale`, `weighted`, `term`, `estimate`, `r2`, `n_cell`, `cv_min`, `cv_max` — the SD–mean relation
used to impute exposure SD per (age × sex) cell for the PAF integral.

## 5. Burden recomputation (Fig 5, Table 4, Table S5–S12)

### `Table4_burden_manuscript.csv`
Manuscript Table 4: global + representative countries; recomputed vs GBD deaths/DALYs, PAF, fold.

### `Table4_m3_decomp.csv`
One row per decomposition step. Key columns: `scenario, role, label, location, year, sigma, m2, tmrel_mode,
tmrel_mims, mean_met_w, mean_mims, cv_eff_dev, pct_below, rrbar_below, rr_scale_used, k_anchor, paf, paf_gbd,
fold, p_tmrel, off_tmrel`. `role` marks the base, the two named adjustments and the faithfulness check.

### `Table9_m3_scenario_summary.csv`
`scenario, role, label, tmrel_mode, sigma, m2, rr_scale_used, n_loc, paf_global, fold_global, fold_min, fold_max` —
the 12-scenario ladder (Table S5).

### `Table10_m3_robustness.csv`
`axis, level, location, cv_wavg, cv_eff_dev, pct_below, rrbar_below, paf, fold` — CV grid (0.40→2.20) and
population-weighting on/off.

### `Table10_m3_country_homogeneity.csv`
Country-scale homogeneity of the device metric (Table S7).

### `M3_BYCOUNTRY_totals.csv`
| Column | Meaning |
|---|---|
| `location`, `year` | GBD location name; 1990 or 2022 |
| `rr_source` | `pooled` (main) / `nhanes` (sensitivity) — **filter to `pooled` for main results** |
| `cv_mode`, `cv_main`, `is_main` | Calibration-variance mode and main-analysis flag |
| `mean_met_wk`, `total_deaths`, `total_dalys` | Exposure mean and GBD cause-combined denominators |
| `recomputed_deaths`, `recomputed_dalys`, `paf_deaths`, `paf_dalys` | Recomputed burden |
| `gbd_deaths`, `gbd_dalys`, `gbd_paf_deaths`, `gbd_paf_dalys` | GBD 2023 reported values |
| `fold_deaths`, `fold_dalys`, `diff_deaths_pct`, `diff_dalys_pct` | Ratios and relative differences |
| `sdi_1990/2022/2023`, `quintile`, `quintile_ord` | SDI and quintile assignment |

> 205 rows per year (204 countries + `Global`). Country statistics must **exclude `Global`** and use
> `rr_source == "pooled"`.

### `M3_BYCOUNTRY_by_cause.csv`
Adds `cause`, `ck`, `deaths_attrib`/`dalys_attrib` with 95% UI, and cause-specific GBD values. All 8 causes
share one RR curve, so `paf_deaths_c` is identical across causes (0.1739584) — between-cause variation comes
from GBD denominators only.

### `Table12_m3_loo_paf.csv`
`scenario, dropped_study, location, year, n_cause, paf, denominator_deaths, recomputed_deaths,
gbd_attrib_deaths, fold` — leave-one-study-out PAF chain (baseline fold 5.667; range 3.80–6.38).

### `Table13_evalues.csv`
E-values for unmeasured confounding, with both the approximate and the direct (rare-outcome) computation:
`hr, lo, hi, direction, ci_crosses_null, rr_approx, e_point_primary, e_ci_primary, e_point_direct, e_ci_direct`.

### `Table14_sdi_anchor.csv`
`location_name, location_id, sdi_1990, sdi_2022, sdi_2023, quintile, quintile_ord, q_source, dist_to_cut,
q_calc_published` — SDI anchor table (205 locations × 3 years; Table S11).

### `TableS4_burden_bycountry_manuscript.csv`
Per-country manuscript-facing table (204 countries, SDI-ordered; Table S12).

### `Fig5d_waterfall_data.csv`
`scope, year, step, from_paf, to_paf, delta_paf, fold_from, fold_to, multiplier, paf_gbd_reported, source` —
each decomposition step with its multiplicative factor.

## 7. Integrity and verification artefacts

| File | Content |
|---|---|
| `manifest.csv` | Every tracked artefact with scope, path, bytes, mtime, hash algorithm and hash (SHA-256) |
| `REPRODUCIBILITY_REPORT.txt` | Five-layer verdict (environment / raw / derived / deliverables / cross-run) |

Currency: none. All ratios are dimensionless.
